# Selection Translator

Chrome/Chromium-расширение для перевода выделенного текста в стиле компактной панели действий: выделил текст, нажал «Перевести» или «Скопировать», получил перевод в маленьком плавающем окне.

Работает как обычное Manifest V3 расширение и подходит для Chrome, Yandex Browser и других Chromium-браузеров, если они поддерживают нужные extension API.

## Что умеет

- Плавающая панель рядом с выделенным текстом.
- Перевод выделенного текста в небольшом окне со скроллом.
- Копирование выделенного текста и готового перевода.
- Контекстное меню браузера для перевода через ПКМ.
- Настройки провайдера, языка, лимита текста и поведения панели.
- Провайдеры: Google web, Yandex web, Yandex Cloud Translate, LibreTranslate endpoint.

## Структура

- `manifest.json` - Manifest V3 конфигурация расширения.
- `src/` - content script, background service worker, переводчики и настройки.
- `popup/` - popup расширения.
- `options/` - страница настроек.
- `assets/` - иконки расширения.
- `tests/` - проверки manifest, UI-скриптов, настроек и переводчиков.

## Запуск в браузере

1. Открой `chrome://extensions`.
2. Включи режим разработчика.
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку этого репозитория: `/home/mazix/Documents/GitHub/Selection-Translator`.

После изменений в `manifest.json` расширение нужно перезагрузить на странице расширений.

## Проверки

```bash
npm run verify
```

## Сборка zip

```bash
npm run pack
```

Готовый архив появится в `outputs/selection-translator-extension.zip`. Папка `outputs/` не версионируется.
