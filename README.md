# Selection Translator

Selection Translator — компактное Chromium-расширение для быстрого перевода выделенного текста прямо на странице. Выделяешь фрагмент, нажимаешь `Перевести` или `Скопировать`, и получаешь результат в аккуратной плавающей панели без перехода на отдельный сайт.

Проект сделан как Manifest V3 расширение и подходит для Chrome, Yandex Browser и других Chromium-браузеров, которые поддерживают нужные extension API.

## Возможности

- Плавающая панель действий рядом с выделенным текстом.
- Перевод в небольшом окне со скроллом для длинных фрагментов.
- Копирование исходного текста и готового перевода.
- Нативное контекстное меню браузера для выделенного текста.
- Настройки провайдера, языка перевода, лимита символов и поведения панели.
- Поддержка Google web, Yandex web, Yandex Cloud Translate и LibreTranslate-compatible endpoint.

## Как выглядит рабочий сценарий

1. Выдели текст на любой обычной веб-странице.
2. Нажми `Перевести` в плавающей панели.
3. Проверь перевод в небольшом окне рядом с выделением.
4. Скопируй исходный текст или перевод одной кнопкой.
5. При необходимости поменяй провайдера и язык в настройках расширения.

## Установка для разработки

1. Склонируй репозиторий.
2. Открой в браузере страницу `chrome://extensions`.
3. Включи режим разработчика.
4. Нажми `Загрузить распакованное расширение`.
5. Выбери папку репозитория.

После изменений в `manifest.json` расширение нужно перезагрузить на странице расширений.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run verify` | Запускает все проверки проекта |
| `npm test` | Запускает тесты через встроенный Node.js test runner |
| `npm run pack` | Собирает zip-архив расширения в `outputs/` |

Готовый архив появляется здесь:

```text
outputs/selection-translator-extension.zip
```

Папка `outputs/` не версионируется.

## CI/CD

В репозитории настроены два отдельных процесса.

### CI

CI запускается на pull request, push в `main` и вручную через GitHub Actions. Он:

- запускает `npm run verify`;
- проверяет, что расширение собирается через `npm run pack`.

### CD

CD запускается только при отправке git-тега версии в формате `vX.Y.Z`, например `v0.1.0`.

Перед публикацией CD:

- сверяет версию тега с `version` в `package.json`;
- сверяет версию тега с `version` в `manifest.json`;
- запускает проверки;
- собирает zip-архив;
- публикует GitHub Release с архивом расширения.

Пример релиза:

```bash
git tag v0.1.0
git push origin v0.1.0
```

Если номер тега не совпадает с версиями в `package.json` и `manifest.json`, релиз остановится.

## Провайдеры перевода

Расширение умеет работать с несколькими провайдерами:

- Google web;
- Yandex web;
- Yandex Cloud Translate;
- LibreTranslate-compatible endpoint.

Для провайдеров, которым нужны ключи или отдельный endpoint, значения задаются в настройках расширения и не хранятся в репозитории.
